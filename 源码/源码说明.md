# 源码说明

本目录是 `SFguard.exe` 的完整源代码，可审阅、可自行构建，用于验证发布包与源码一致。

## 目录

```
源码/
├─ main.py                 入口：图形界面 / 命令行 / 自检
├─ sfguard/
│   ├─ __init__.py         版本信息
│   ├─ ioc.py              特征库（哈希、进程名、路径、注册表、任务、端口）
│   ├─ util.py             权限、目录、日志、命令执行、哈希、注册表、隔离区
│   ├─ scanner.py          体检引擎（7 组检查、快照采集、评分）
│   ├─ fixer.py            修复引擎（动作可回滚，注册表先备份）
│   ├─ envguard.py         环境自检与自修复
│   ├─ report.py           报告生成（Markdown / HTML / JSON）
│   └─ gui.py              Tkinter 界面
├─ build.ps1               PyInstaller 单文件打包（含自检与完整性级别修正）
├─ version_info.txt        Windows 版本资源
├─ make_icon.py            生成 assets/app.ico
└─ assets/                 图标
```

## 构建

需要 Python 3.9+（64 位 Windows）：

```powershell
cd 源码
python -m pip install pyinstaller pillow
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物输出到本目录上级的 `SFguard.exe`。脚本会先跑 18 项自检，再用产物自检一次，任一失败即中止。

## 运行源码（不打包）

```powershell
python main.py                 # 图形界面
python main.py --scan          # 只读体检
python main.py --selftest      # 自检
```

## 说明

- 程序数据（日志、隔离区、报告）默认写入 `C:\ProgramData\SFguard`，
  无写权限时退回 `%LOCALAPPDATA%\SFguard`。
- 体检不需要管理员权限；修复需要提权，程序会主动发起 UAC。
- 所有修复动作均有前置校验与备份：文件进隔离区、注册表写 JSON 备份、hosts 备份 `.bak`。
